=========================================================================
SIMAK SMAI DUBA — PAKET APLIKASI v2 (Alumni + Staf dalam SATU aplikasi)
=========================================================================
Yang baru di v2
  * Satu aplikasi untuk semua: layar pilihan Alumni / Staf muncul di dalam
    aplikasi; pilihan terakhir diingat (bisa dimatikan di config.js).
  * Halaman cetak (raport, ijazah, buku induk, absen, SK) terbuka di penampil
    DALAM aplikasi, bukan di tab/jendela lain.
  * Tombol Kembali HP menutup penampil cetak; tombol "Kembali ke Pemilihan"
    tetap di dalam aplikasi.

Isi paket
  index.html            pembungkus layar penuh + penampil cetak
  config.js             <- SATU-SATUNYA yang perlu Anda ubah (alamat aplikasi)
  manifest.webmanifest  data aplikasi (nama, warna, ikon)
  sw.js                 service worker
  icons/                ikon bawaan (boleh diganti logo sekolah)
  .nojekyll             (hanya untuk GitHub Pages; abaikan)

Cara memakai
  1) Pasang dulu Patch_satu_aplikasi.txt (BAGIAN 1-4) di Apps Script, lalu
     Deploy > Manage deployments > Edit > New version > Deploy.
  2) Isi config.js: APP_URL = alamat dasar /exec (TANPA ?staff=1).
  3) Seret folder ini ke Netlify (Deploys > kotak drag and drop) untuk
     memperbarui situs yang sudah ada. Pemasangan pertama: lihat langkah
     di PETUNJUK lama (Netlify Drop, lalu "Instal aplikasi" di Chrome).
  4) Tutup aplikasi sepenuhnya di HP lalu buka lagi.

Bila ada masalah
  * Layar putih / "refused to connect": ALLOWALL atau New version belum beres.
  * "Alamat aplikasi belum diisi": config.js belum diubah.
  * Pilihan lama (staf) selalu langsung terbuka dan Anda ingin layar pilihan:
    di aplikasi staf/alumni ketuk "Kembali ke Pemilihan", atau ubah
    INGAT_PILIHAN menjadi false di config.js.
  * Dialog cetak tidak muncul saat menekan "Cetak": ketuk tombol ↗ di penampil
    untuk membukanya di Chrome lalu cetak dari sana, dan kabari saya (sebutkan
    tipe HP dan versi Chrome) agar dibuatkan cadangan PDF.
